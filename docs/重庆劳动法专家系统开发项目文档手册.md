# 重庆劳动法专家系统开发项目文档手册


## 1. 项目概述

### 1.1 项目背景
本项目旨在构建一个专业的重庆地区劳动法智能咨询系统，为用户提供基于重庆本地法律条文和判例的劳动仲裁建议、赔偿计算等服务。系统采用多Agent架构设计，确保专业性、准确性和可扩展性。

### 1.2 项目目标
- 构建专门针对重庆地区劳动法的智能咨询系统
- 提供准确的法律条款溯源和判例参考
- 实现高效的赔偿计算和仲裁建议生成
- 支持多模态输入和用户意图识别
- 确保系统的安全性、可靠性和高性能
- 支持外部劳动法数据集的动态集成
### 1.3 技术栈
- 后端框架：FastAPI + LangGraph
- 大语言模型：Azure OpenAI / 自定义LLM
- 数据库：SQLite / ChromaDB
- 缓存系统：Redis
- 部署方式：Docker容器化
- 安全认证：JWT令牌认证

- **仲裁顾问Agent (ChongqingArbitrationAdvisor)**: 仲裁策略建议生成

#### 2.2.2 Agent通信机制
```python
class CommunicationManager:
    """
    Agent间通信管理器
    """
    def __init__(self):
        self.agents = {}
        self.message_queue = asyncio.Queue()
    
    async def send_message(self, sender_id: str, receiver_id: str, message: dict):
        """发送消息给指定Agent"""
        await self.message_queue.put({
            'sender': sender_id,
            'receiver': receiver_id,
            'message': message
        })
    
    async def broadcast_message(self, sender_id: str, message: dict):
        """广播消息给所有Agent"""
        for agent_id in self.agents:
            if agent_id != sender_id:
                await self.send_message(sender_id, agent_id, message)
```

## 4. 安全防护机制

### 4.1 JWT令牌认证
```python
from fastapi.security import OAuth2PasswordBearer
from jose import jwt, JWTError
from datetime import datetime, timedelta

class AuthManager:
    """
    认证管理器
    """
    
    def create_access_token(self, data: dict, expires_delta: timedelta = None):
        """创建访问令牌"""
        to_encode = data.copy()
        if expires_delta:
            expire = datetime.utcnow() + expires_delta
        else:
            expire = datetime.utcnow() + timedelta(minutes=30)
        to_encode.update({"exp": expire})
        encoded_jwt = jwt.encode(to_encode, SECRET_KEY, algorithm=ALGORITHM)
        return encoded_jwt
    
    def verify_token(self, token: str):
        """验证令牌"""
        try:
            payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
            return payload
        except JWTError:
            return None
```

### 4.2 输入安全防护
```python
class InputSanitizer:
    """
    输入安全清理器
    """
    
    @staticmethod
    def sanitize_input(user_input: str) -> str:
        """
        清理用户输入，防止注入攻击
        """
        # 移除危险字符
        dangerous_chars = ['<script>', '</script>', '--', '/*', '*/']
        sanitized = user_input
        for char in dangerous_chars:
            sanitized = sanitized.replace(char, '')
        return sanitized
    
    @staticmethod
    def validate_input_length(input_str: str, max_length: int = 1000) -> bool:
        """
        验证输入长度
        """
        return len(input_str) <= max_length
```

```python
class CacheManager:
    """
    缓存管理器
    """
    
    def __init__(self):
        self.redis_client = redis.Redis(host='localhost', port=6379, db=0)
    
    def get_cached_response(self, key: str) -> Optional[str]:
        """获取缓存响应"""
        cached = self.redis_client.get(key)
        return cached.decode('utf-8') if cached else None
    
    def cache_response(self, key: str, response: str, ttl: int = 3600):
        """缓存响应"""
        self.redis_client.setex(key, ttl, response)
```

```python
            documents=[content],
            metadatas=[metadata],
            ids=[article_id]
        )
    
    def query_law(self, query: str, top_k: int = 5) -> List[dict]:
        """查询法律条文"""
        results = self.collection.query(
            query_texts=[query],
            n_results=top_k
        )
        return results['documents'][0]
```

#### 10.3.1 数据导入架构
系统支持外部劳动法数据集、判决文书典例和指导意见的动态集成，采用以下架构：

- **数据导入模块**：`app/services/data_importer.py` 提供统一的数据导入接口
- **多格式支持**：支持JSON、CSV等常见数据格式
- **向量数据库集成**：自动将数据转换为向量并存储到ChromaDB
- **元数据管理**：为每条数据添加类型、来源、时间等元信息

#### 10.3.2 支持的数据类型

1. **劳动法数据集**：
   - 法规名称、编号、适用范围
   - 主要内容、生效日期、修订版本

2. **判决文书典例**：
   - 案件编号、类型、审理法院
   - 案件事实、判决结果、裁判要点
   - 法律依据等关键信息

3. **指导意见**：
   - 指导意见标题、发布机构
   - 发布日期、适用范围、政策要点
