## 已知风险

- 当前环境未安装 `pytest`，正式回归请继续使用 `unittest` 路径或补齐测试依赖。
- `LLM_PROVIDER` 未配置时会回退本地规则模式，外部模型能力不会自动启用。
- 生产环境仍需独立准备 `.env.production`、域名、HTTPS 与 API Key。

## 运行手册

### 本地开发

1. 安装后端依赖：`pip install -r requirements.txt`
2. 安装前端依赖：`cd frontend && npm install`
3. 启动前端：`cd frontend && npm run dev`
4. 启动后端：`uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000 --reload`

### 生产部署

1. 复制环境文件：`cp .env.production.example .env.production`
2. 填好 `SERVER_NAME`、`DEEPSEEK_API_KEY`、`CORS_ALLOWED_ORIGINS`、`ALLOWED_HOSTS`、`SESSION_COOKIE_SECURE`
3. 启动：`docker compose up -d --build`
4. 查看状态：`docker compose ps`
5. 查看日志：`docker compose logs -f app`

### 日常操作

- 登录后可在侧边栏保存案件、查看历史、修改资料和密码。
- 录入事实与证据后先点“整理案情并评估”，再点“生成文书”。
- 生成文书后系统会自动做一致性校验。
- 旧版浏览器记录可通过“导入旧版记录”迁移到服务端。
